PUTTING THE WEATHER RELAY IN PLACE
==================================

WHY BOTHER
----------

Right now every single visitor's browser asks the weather service for
itself. A hundred visitors is a hundred requests, and the key sits in
the website's code where anyone can read it.

This relay fixes both. It asks once, holds the answer ten minutes, and
hands that same copy to everyone. The key lives at Cloudflare instead
of on the website.

It costs nothing. Cloudflare's free allowance is 100,000 requests a
day; this uses a few hundred at most.


WHAT YOU DO — ABOUT TEN MINUTES
-------------------------------

1. Go to dash.cloudflare.com and sign in.

2. In the left sidebar click "Workers & Pages", then "Create", then
   "Start with Hello World!" and click "Deploy".

   Name it:   gray-man-weather

   (Cloudflare insists on deploying its example first. That's fine —
   you're about to replace it.)

3. Click "Edit code". Delete everything in the editor, then paste in
   the entire contents of the file  weather-worker.js  which sits
   beside this one.

   Click "Deploy" (top right).

4. Now give it the weather key. Leave the editor and go to the
   worker's "Settings" tab, then "Variables and Secrets".

   Click "Add", and choose type "Secret".

     Name:    OWM_KEY
     Value:   25d669ff5870ef3620d05f24b9350106

   Save, and deploy again if it asks.

   The word "Secret" matters — it means the key is stored hidden
   rather than shown in plain text.

5. Find the relay's address. On the worker's overview page it looks
   like:

     https://gray-man-weather.SOMETHING.workers.dev

   Copy that whole address.

6. Open content.js in the main website folder. Find "proxy_url" in
   the weather section and paste the address between the quotes:

     proxy_url: "https://gray-man-weather.SOMETHING.workers.dev",

7. Push the change in GitHub Desktop. Done.


HOW TO TELL IT WORKED
---------------------

Open the relay's address directly in a browser. You should see a
block of weather text starting with {"coord":...

Then load the website and confirm the conditions still appear.


AFTERWARDS
----------

Once the relay is running, the key in content.js is no longer used by
the website. It's worth generating a fresh key at openweathermap.org,
putting the new one into Cloudflare as above, and retiring the old one
— since the old one has been publicly visible.

Ask Claude if you'd like help with that step.


IF YOU'D RATHER NOT
-------------------

Leaving "proxy_url" empty is fine. The weather still works exactly as
it does today — each visitor just asks the service themselves. For a
site of this size that is unlikely to cause trouble. The relay is the
tidier answer, not a required one.
